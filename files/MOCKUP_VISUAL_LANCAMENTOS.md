## 💡 Atalhos de Teclado Sugeridos

| Tecla         | Ação                           |
|---------------|--------------------------------|
| `Ctrl + N`    | Novo lançamento                |
| `Ctrl + F`    | Abrir filtros                  |
| `Ctrl + E`    | Exportar dados                 |
| `Esc`         | Fechar modal                   |
| `Enter`       | Salvar (quando modal aberto)   |

## 📱 Responsividade

### Desktop (> 1024px)
- 3 cards de resumo lado a lado
- Tabela completa com todas as colunas
- Gráficos visíveis

### Tablet (768px - 1024px)
- 3 cards empilhados
- Tabela com scroll horizontal
- Gráficos simplificados

### Mobile (< 768px)
- Cards em coluna única
- Tabela em formato de lista (cards)
- Botão flutuante "+" para novo lançamento
